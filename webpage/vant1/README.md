# 模拟投资
先总结下，AI可以生成代码，可是这个代码是无法使用的。
- 第一BUG是非常多的，需要修改。
- 第二很多地方和你设想和描述的是不一样的，要一一的修改。

所以还是要，自己些代码实现。



### 概述

一直想开发个模拟基金投资的APP，用来模拟基金投资。

主要功能，

- 1，模拟基金每天的涨跌
- 2，模拟买卖基金
- 3，模拟统计基金每天的涨跌，对资产份额的改变。
- 4，模拟统计，现在的资产是多少。





此项目起源于2023-3-7
